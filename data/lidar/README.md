# Example airborne LiDAR point clouds

`Megaplot.laz`, `MixedConifer.laz` and `Topography.laz` are the example files
shipped with the lidR R package (Roussel et al. 2020, Remote Sensing of
Environment 251:112061, doi:10.1016/j.rse.2020.112061), licensed GPL-3.
Source: https://github.com/r-lidar/lidR/tree/master/inst/extdata

They are small enough to keep in the repository and are used by Chapter 32
(`scripts/py/ch32_lidar_trees.py`). Real survey tiles (GBs) do not belong in git.
